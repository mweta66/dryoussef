# Cairo

`cairo-variable.woff2` is served locally; the application does not request a font service.
It includes the full Arabic and Latin character sets and weights 200–1000.

Source: [Google Fonts Cairo](https://github.com/google/fonts/tree/main/ofl/cairo),
`Cairo[slnt,wght].ttf`, retrieved 2026-10-19.
Copyright 2009 The Cairo Project Authors (https://github.com/Gue3bara/Cairo).
The SIL Open Font License is included in `OFL-Cairo.txt`.

The normal, zero-slant instance was generated with FontTools' variable-font
instancer (`slnt=0`), retaining the weight axis and all glyphs, then compressed
to WOFF2 with Brotli. No application runtime dependency is needed.
