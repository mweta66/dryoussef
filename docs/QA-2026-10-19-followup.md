# تحقق تحسينات العيادة — 19 أكتوبر 2026

## النطاق والبيانات

الفحص على نسخة محلية معزولة من بيانات التدريب، دون تعديل بيانات الإنتاج. التغييرات لا تضيف خدمة خارجية؛ تستخدم Vercel وSupabase الموجودين. واتساب رابط يفتحه المستخدم بنفسه، وليس إرسالاً تلقائياً.

## ما تم اختباره

- نجح الاختبار الكامل: 276 اختباراً، وفحص صياغة 200 ملف JavaScript، وبناء الواجهة والملف المجمع للخدمة.
- اختبارات Node ونسخة Edge تشمل الصلاحيات وحدود الفروع، تقليل بيانات الاستعلام العام، مهلة تعديل الموعد، وإخفاء قسم الطلبات من الأدمن.
- إغلاق النموذج يحفظ النص قبل إزالة الحقول؛ اختبارات ترتيب الحفظ، وفشل الشبكة وإعادة المحاولة، والخروج وعدم انتقال مسودة لحساب آخر.
- رفع PDF أصلي أكبر من حد الصور القديم وتنزيله، ورفض الملفات المزيفة والكبيرة والمستخدمين غير المخولين. المرفقات خاصة ولا تُعرض داخل iframe.
- نسخة قديمة بها 1001 تقرير، وأجزاء صحيحة/تالفة/مكررة/من أرشيف مختلف. استعادة نفس التقرير مرتين لا تنشئ ملفاً جديداً. حساب التقدم يتتبع معرف المصدر عبر جلسات الاستعادة.
- Chromium: تنزيل أرشيف مشفر من ملف تعريف وجزأين، واختيار كل جزء مع التعريف بالتتابع، وإلزام الإقرار بالاستعادة الجزئية، وإعادة الاستعادة دون زيادة عدد المرفقات.
- Chromium: تأخير تحميل الإعدادات 8.5 ثانية؛ الشعار ظاهر والمحتوى القديم مخفي، ثم فتح الصفحة عند جاهزيتها. قطع الطلب الأول ثم عودة الاتصال أعاد التحميل بنجاح دون ريفريش. اختبار انتظار تحميل Cairo قبل إظهار الصفحة.
- Chromium: إدخال الهاتف فقط يُظهر الحجز الحالي؛ اختيار الخميس يقترح مطروح حسب جدول الاختبار. الطلب لا ينقل الحجز مباشرة. السكرتارية بالإسكندرية ترى التنبيه عند الدخول، وسكرتارية الفرع الآخر لا ترى عدد طلبات لا تخصها.
- الدخول للحسابات الثمانية (الأدمن والطبيب والممرضة وأربع سكرتاريات ومدخل البيانات): لا تبويب أدوات العيادة، ولا تمدد أفقي عند عرض 390px. التحقق لا يعني تجربة كل زر في النظام أو اختبار كل صلاحية يدوياً.
- الصفحة العامة بأحجام 320 و768 و1366px دون تمدد أفقي. صفحات الفروع الأربع تعيد 200 بجدول وبيانات حالية وSchema، ورابط واتساب الصحيح. اختبارات SSR تشمل إخفاء فرع، وانقطاع مصدر الإعدادات، وهروب HTML/JSON ومنع إدراج بيانات المرضى.
- تحذير التباين الأبيض على الأبيض للنبذة ورسالة الطوارئ؛ رفض التأكيد يمنع الحفظ. لوحة الأدمن تعرض توافق إصدار الواجهة والخدمة.
- محاكاة خدمة أقدم ترفض نقاط API الجديدة: عرض حجوزات الهاتف وتنبيه الطلبات يعملان عبر المسارات القديمة المخولة. اختيار الإلغاء يخفي التاريخ الجديد والفرع ولا يفرض ملأهما.
- رابط واتساب الصحيح هو https://wa.me/201275884716. لا يتم إرسال اسم أو هاتف مريضة أو معلومة طبية ضمن نص الرابط.

## حدود فعلية

- اختبارات المتصفح على Chromium المثبت، وليس Safari أو Firefox أو Edge الفعليين. لا ادعاء باختبار شامل لكل متصفح أو كل إجراء يدوي.
- لم يُجرَ اختبار ضغط على الإنتاج، ولم تُقَس Core Web Vitals ميدانياً.
- تعذر الاتصال بنسخة Vercel الحية من شبكة البيئة. لا توجد صلاحيات نشر Supabase متاحة في الجلسة؛ اختبارات API محلية ونسخة Edge، وليست تأكيداً لنشر الإنتاج.
- المرفقات: الصور 600 كيلوبايت، PDF خمسة ملايين بايت، و20 مرفقاً لكل حالة. الأرشيف المقسم حتى 256 ميجابايت، الجزء حتى 8 ميجابايت، والبيانات الطبية وحدها حتى 8 ميجابايت. ليست هذه آلية بث لنسخ احتياطية غير محدودة؛ يحجز المتصفح بيانات الأرشيف في الذاكرة.
- الاستعادة تضيف الجديد وتحافظ على السجلات الحالية والمتعارضة؛ لا تستبدل قاعدة البيانات بالكامل ولا تستورد كلمات السر أو الحسابات. تنزيل نسخة لا يثبت نسخها خارج الجهاز أو نجاح استعادة الإنتاج.
