# تحديث اللوجو والتحميل واستيراد الحالات

- الشعار الافتراضي الجديد `public/brand-current.webp` بخلفية شفافة، ويظهر في الهيدر وشاشة الدور وأثناء التحميل. الشعار المخصص المحفوظ من إعدادات الأدمن يظل له الأولوية.
- تظهر دائرة تحميل حول الشعار. ينتهي هذا العرض خلال 2.9 ثانية، أو قبلها إذا اكتملت البيانات والتنسيقات. عند بطء الشبكة تظهر واجهة انتظار محايدة مع إعادة المحاولة؛ لا تُعرض بيانات قديمة أو إعدادات افتراضية مكان الإعدادات المحفوظة. مدة اتصال الشبكة نفسها ليست مضمونة.
- تحميل حساب الموظف يجمع الصلاحيات والإعدادات وبيانات الشاشة في طلب workspace، مع طلب إضافي عند الانتقال إلى التبويب المسموح أو تحديث ملفات العرض القديمة.
- استيراد TXT/TSV يدعم الأعمدة: «م»، «اسم الحالة الرباعي»، «رقم الهاتف المصري»، «نوع الزيارة»، «الفرع»، «الملاحظات الطبية». يُحفظ الفرع ونوع الزيارة على ملف الحالة عند عدم وجود تاريخ؛ إنشاء حجز يتطلب تاريخًا وفرعًا صحيحين. نوع «طوارئ» في ملف بلا تاريخ لا ينشئ دورًا أو يبدأ جلسة.
- لا تُستكمل بيانات زوج أو تواريخ غير موجودة بالملف تلقائيًا. تُرفض الفروع غير المعروفة. تظل المعاينة والموافقة والصلاحيات ومنع التكرار مطلوبة كما كانت.

## النشر

1. دمج فرع التعديلات ونشر أحدث نسخة عبر Vercel.
2. نشر `deployment/clinic-api.js` المحدث كوظيفة Supabase الحالية، مع الإبقاء على إعداداتها وأسرارها. رفع الواجهة وحدها لا يحدث خدمة البيانات.
3. من حساب الأدمن: الإعدادات ← استيراد بيانات العيادة ← اختيار ملف JSON المجهز أو ملف TXT/TSV، ثم مراجعة توزيع الفروع في المعاينة قبل التنفيذ.

بيانات الحالات المرفوعة ونسخها الاحتياطية محفوظة محليًا في ملفات خاصة مستثناة من Git. لا تُرفق ملفات المرضى بهذا المستند أو بمرفقات Pull Request.

## التحقق

`npm run check` و`npm test`. تشمل الاختبارات بوابة ظهور البيانات الحديثة، تأخر التنسيق، استيراد TSV بلا تاريخ مع الملاحظات والفرع، وعدم تكرار السجلات. اختبارات المتصفح المحلية تشمل تأخر البيانات وCSS وملف بدء التشغيل أكثر من ثلاث ثوانٍ، وحسابات المستخدمين ومقاسات الشاشة.
