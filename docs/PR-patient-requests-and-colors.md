للأدمن مفتاح لإظهار أو إخفاء قسم طلبات المواعيد العام بالكامل. الإخفاء يشمل الحجز الجديد والتغيير والإلغاء، وتمنعه الخدمة أيضًا عبر API، مع بقاء الاستعلام بالموبايل والطلبات السابقة. التحديث يعالج كذلك خطأ تجهيز حجز الموظفين الذي كان يعمل عند تغيير تاريخ نموذج المريضة.

تغيرت الألوان إلى أزرق هادئ ووردي منخفض التشبع، مع أسطح داكنة وأزرار أقل سطوعًا، وإزالة المساحة الذهبية الكبيرة من شاشة الدور. تُطبّق الألوان وصلاحية عرض الممرضة مرة واحدة عند دخول الأدمن بعد نشر الخدمة؛ لا يعاد فرضها على اختياراته التالية، ولا تتغير بيانات الحالات أو المقاسات والصور والنصوص.

التحقق: 254 اختبارًا ناجحًا، فحص JavaScript، وبناء Edge موحد. تجربة Chromium محلية من نماذج المرضى إلى حساب الممرضة، ومفتاح إخفاء القسم وإعادته من الأدمن، دون أخطاء JavaScript أو تمدد أفقي في الزيارات المختبرة. اختبارات Node وEdge تغطي الصلاحيات، منع تجاوز الإخفاء، بقاء الطلبات السابقة، التحديث التلقائي، وعزل الحسابات. تفاصيل المراجعة في docs/QA-2026-10-19-requests-colors.md.
