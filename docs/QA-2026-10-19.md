# مراجعة التغييرات الداخلية — ١٩ أكتوبر ٢٠٢٦

- ٢٤٢ اختبارًا آليًا ناجحًا في Node، تتضمن التحقق من تنفيذ Edge: الصلاحيات، حدود الفروع، ثبات التذكرة عند الوصول، عزل المسودات، مراجعة طلبات المريضة، الدمج والتراجع مع تعارض الإصدارات، الاستيراد الكبير، والتشفير وكلمة السر الخاطئة والعبث بالملف.
- فحص بناء الجملة لكل ملفات JavaScript، وبناء ملف Edge الموحد.
- Chromium محلي: أدوات العمل في الحسابات الثمانية بلا أخطاء JavaScript أو تمدد أفقي عند 390px. بيانات وكلمات مرور الاختبار في نسخة معزولة؛ لم تتغير حسابات أو سجلات الإنتاج.
- رحلة طلب الحجز العامة ثم ظهور الطلب للأدمن، إنشاء مهمة، حفظ مسودتها الخاصة، نجاح حفظها، والاحتفاظ بالقسم بعد Refresh.
- تغيير لون رسالة الطوارئ من الأدمن ظهر في نافذة العرض؛ محررها غير موجود في النافذة. لا يستطيع مفوض إدارة العرض تغيير تصميم الطوارئ عبر API.
- الصفحة العامة عند 320 و390 و768 و1366px دون تمدد أفقي. حُمّل ١٧ ملف script بدل محررات الطاقم الكاملة. لا تمثل هذه النتيجة قياس Core Web Vitals حقيقيًا للإنتاج.
- لم تُختبر Safari أو Firefox أو Edge فعليًا. حجب الشبكة الوصول إلى Vercel وGitHub API؛ فحص النسخة المنشورة وفتح PR عبر API يحتاج وصولًا متاحًا.
- ترحيل تجربة الاستعادة الدورية أُعدّ للمراجعة ولم يُشغّل على قاعدة حية في هذه البيئة. تجربة JSON لا تتحقق من الصور أو حسابات Auth.
- لا ربط جديد لخدمة خارجية، ولا رسائل SMS/WhatsApp تلقائية، ولا رفع تلقائي لنسخة خارج المشروع.

هذه أرقام خادم التطوير المحلي، وليست الطاقة القصوى لـVercel أو Supabase أو ضمانًا لعدد مستخدمي الإنتاج. لم يُنفذ ضغط على الموقع الحي.

مراجعة الألوان: وُحّدت ألوان الروابط والأزرار الثانوية، وحقول الإدخال وحالتها المعطلة، والمؤشرات والنجاح والخطأ مع متغيرات الثيم. صُحّح نص الأزرار الخضراء والحمراء وأيقونة الطوارئ في الوضع الداكن، حيث كانت الخلفية الفاتحة تحمل نصًا أبيض منخفض التباين. يبقى لون تصميم رسالة الطوارئ اختيارًا للأدمن مستقلًا عن ثيم الموظف.

الدارك مود: تصفح ٥٦ قسمًا متاحًا للحسابات الثمانية في Chromium عند 390px، بالإضافة للواجهة العامة ونموذج الحجز وشاشة الدور. صُحّحت ألوان زر القسم النشط وأزرار الهيدر، وأضيف دعم الدارك لصفحة الخصوصية وصفحة 404 وشاشة التحميل نفسها، لمنع خلفية بيضاء ساطعة أثناء الانتظار. اختُبرت ١٠٠ مقارنة تباين من الثيمات العشرة في الوضعين، وبلغت 4.5:1 على الأقل في المقارنات المختبرة. لا تشمل النتيجة كل لون مخصص يختاره الأدمن لاحقًا.
