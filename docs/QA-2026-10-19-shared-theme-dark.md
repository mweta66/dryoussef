# إلغاء الثيمات الشخصية وتباين الوضع الداكن

- يُحذف تخصيص الألوان الشخصية من الواجهة، وتظل إدارة تصميم العيادة في لوحة الأدمن. زر النهاري/الليلي مستقل عن تخصيص الألوان.
- الاختيارات القديمة في `clinic_staff_theme_*` أو `userPreferences` لا تؤثر في التصميم؛ لا حاجة لمسح بيانات المتصفح.
- اختبار Node وEdge يثبت رجوع إعداد محايد لكل الأدوار، ورفض `preferencesSave` بـ403 حتى للعميل القديم، ورفض الحساب المعطل أو الطلب غير المصادق عليه، وعدم تغيير السجلات أو التفضيلات المخزنة.
- اختبارات التباين تشمل الإعدادات العشرة، والألوان القديمة المحفوظة، واختيارات ضعيفة التباين أو بيضاء بالكامل. الهدف للنص الأساسي 7:1، والثانوي 5.5:1، وحدود الحقول مع الأسطح المجاورة 3:1، والأزرار 4.5:1 على الأقل. أرقام شاشة الدور لها حد 7:1 في الدارك. تعمل المعالجة عند العرض ولا تحفظ درجات بديلة في قاعدة البيانات.
- 258 اختبارًا ناجحًا، فحص بناء الجملة لـ179 ملف JavaScript، وبناء `deployment/clinic-api.js` باستخدام esbuild المثبت الإصدار.
- تجربة Chromium محلية مع 500 حالة تدريبية في نسخة معزولة: الأدمن والطبيب والسكرتارية الأربعة والممرضة ومدخل البيانات. شملت 75 زيارة لشاشات وأقسام، وفحص غياب أدوات الثيم الشخصي، وتجاهل اختيار قديم محفوظ، وبقاء أدوات التصميم لدى الأدمن، ورفض حفظ التفضيلات عبر API.
- لا أخطاء JavaScript أو تمدد أفقي في الزيارات المختبرة. فُحصت النصوص الظاهرة برمجيًا باستخدام ألوان النص والخلفية المحسوبة، وعُوينت لقطات الأدمن على الهاتف وشاشة الدور على الكمبيوتر. هذا فحص تباين للألوان المحسوبة؛ لا يمثل اعتماد WCAG شاملًا أو قياسًا لكل بكسل فوق الصور.
- مراجعة الصفحات العامة والخصوصية و404 وشاشة الدور عند عرض 320 و768 و1366 بكسل؛ مراجعة أقسام الطاقم عند 390 بكسل.
- لم تتغير ملفات التجربة الأصلية أو بيانات الإنتاج. لم تتوفر أداة لنشر Supabase؛ يلزم نشر الواجهة والخدمة معًا. لم تُختبر محركات Safari أو Firefox أو Edge فعليًا.
