# أدلة استخدام العيادة — فيديوهات رأسية مختصرة

أربعة فيديوهات مستقلة، كل فيديو حوالي دقيقتين ونصف، بمقاس 720 × 1280 مناسب للموبايل وواتساب، وبشرح مصري مكتوب دون صوت. تسجيل استخدام فعلي من نسخة محلية معزولة؛ قد تختلف النسخة المنشورة عنها.

الأمثلة بأسماء محايدة مثل «المريضة الأولى»، وأرقام الموبايل محجوبة. يبدأ الشرح داخل واجهة كل دور، دون عرض بيانات الدخول.

| الفيديو | المهام | التنزيل |
| --- | --- | --- |
| المرضى | الاستعلام، طلب حجز، واتساب | [MP4](01-patients.mp4?raw=true) |
| الدكتور | الطابور والحضور وجلسة الكشف والملف الطبي | [MP4](02-doctor.mp4?raw=true) |
| السكرتارية | الحجز والحضور وحالة الكشف وطلبات المرضى | [MP4](03-secretary.mp4?raw=true) |
| الممرضة | البحث والشكوى والعلاج الموصوف والتقارير والطباعة | [MP4](04-nurse.mp4?raw=true) |

[تحميل الحزمة كاملة](clinic-user-guides.zip?raw=true).

كل فيديو مستقل، ولا يحتاج مشاهدة فيديو دور آخر. عند مشاركة الدليل مع مستخدم، شارك فيديو دوره.

لو ظهر الملف في صفحة GitHub، اضغط Download raw file. بعد التنزيل افتح MP4 من الملفات أو المعرض. لفهرس الفيديوهات، فك ضغط الحزمة ثم افتح index.html. ملفات script.txt تحتوي نصوص الشرح بتوقيتاتها؛ الفيديوهات نفسها بدون صوت.

الملفات القديمة استُبدلت بهذه النسخ المختصرة. بصمات الملفات ومواصفاتها موجودة في media-checks.json.
