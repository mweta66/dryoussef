# استيراد بيانات العيادة

من حساب الأدمن: «إعدادات حسابي» ← «استيراد بيانات العيادة».

1. اختر نسخة JSON مصدرة من التطبيق، أو XLSX، أو CSV بترميز UTF-8. يمكن قراءة النسخ الآلية التي تحتوي payload أيضًا.
2. لملفات الجداول: نزّل قالب CSV الذي يفتح في Excel واملأ الأعمدة. الاسم name والهاتف phone مطلوبان. اترك branch وdate فارغين لإضافة ملف مريض فقط، أو أدخلهما معًا لإنشاء حجز. الفرع dmn أو alex، والتاريخ YYYY-MM-DD. نوع الزيارة exam أو cons أو follow أو emergency. أعمدة notes وmedical_notes والحساسية والتشخيص والعلاج اختيارية. أسماء الأعمدة العربية الشائعة مدعومة أيضًا.
3. لو ملف Excel متعدد الأوراق، اختر الورقة المطلوبة. تُقرأ الورقة المختارة فقط ضمن عملية الاستيراد.
4. استيراد الإعدادات والتصميم من JSON اختيار منفصل غير مفعّل افتراضيًا.
5. اضغط «معاينة وفحص». راجع أعداد الجديد والمكرر والمتعارض، والتذاكر التي ستُعاد أرقامها، والكشوف التي ستتحول إلى الانتظار.
6. فعّل الموافقة ثم اضغط «تنفيذ الاستيراد». انتظر رسالة النجاح. إذا تغيرت بيانات العيادة أو الملف بعد المعاينة، يجب إعادة المعاينة.

## سياسة البيانات

الإضافة فقط: لا تُحذف أو تُستبدل سجلات موجودة. تُترك السجلات المتعارضة والملفات الطبية الموجودة كما هي. لا يُستورد حجز ثان للهاتف نفسه في اليوم نفسه. اختلاف اسم مريض موجود يمنع إلحاق بيانات طبية مستوردة به. الحجوزات المحذوفة لا تُستعاد ضمن الاستيراد؛ لها وظيفة الاسترجاع المخصصة. أرقام التذاكر المتعارضة تُخصص من آخر رقم مستخدم دون إعادة استعمال الأرقام المحذوفة.

حسابات الدخول والصلاحيات وكلمات المرور والجلسات والتنبيهات لا تُستورد. الحالة المستوردة «جاري الكشف» تتحول إلى «في الانتظار»، ولا تبدأ جلسة طبيب تلقائيًا. تُحفظ الملاحظات الطبية السابقة للمتابعة إن وجدت بالنسخة دون إعادة وحدة مواعيد المتابعة إلى الواجهة.

الاستيراد يراجع الملف كاملًا على الخادم وينفّذ التغيير دفعة واحدة. المعاينة مرتبطة بالبيانات والخيارات وحالة العيادة وحساب الأدمن وتاريخ اليوم؛ لا يُقبل تطبيق معاينة قديمة. لا تُرسل ملفات XLSX لخدمة خارجية؛ تُقرأ محليًا ثم تُرسل البيانات المختارة لخادم العيادة عند المعاينة.

## الحدود والتحقق

- XLSX حتى 5 ميجابايت، وJSON/CSV حتى 850 كيلوبايت. البيانات المحولة إلى JSON لا تتجاوز 850 كيلوبايت. حتى 1000 صف جدول أو 1000 حجز في عملية واحدة؛ قسّم الملفات الأكبر.
- حماية لحجم المحتوى المفكوك من Excel، والتحقق من الهواتف والتواريخ والمعرّفات والأطوال وحقول JSON غير الآمنة.
- قارئ Excel: read-excel-file 9.3.12، نسخة متصفح محلية مثبتة الإصدار مع ترخيص MIT في public/vendor. لا يُحمّل القارئ إلا عند اختيار XLSX. package-lock.json يثبت الاعتماديات.
- الاختبارات: CSV عربي واقتباسات وأسطر متعددة، XLSX فعلي متعدد الأوراق، استيراد JSON ومعاينة قديمة، عدم التكرار أو استبدال الملفات الطبية، منع الأدوار غير الإدارية، التطبيق المتزامن، وعدم حدوث إضافات جزئية عند الخطأ.
