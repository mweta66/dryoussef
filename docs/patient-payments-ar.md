# وسائل دفع المرضى ورسالة السعر والإثبات

الإصدار: **2026.11.04.1**. التغيير جاهز في الكود ويحتاج نشر خدمة clinic-api ثم الواجهة المطابقة. لا يوجد SQL جديد. البيانات الافتراضية تخفي قسم الدفع حتى يفعله الطبيب أو الأدمن ويضع بياناته الفعلية؛ لا يوجد رقم محفظة أو سعر افتراضي من بيانات الاختبار.

## الاستخدام

من حساب الطبيب أو الأدمن: **إعدادات حسابي ← إعداد وسائل الدفع**.

- اكتب الرسالة المطلوبة، مثل سعر الكشف وتعليمات التحويل وإرسال الإيصال. الرسالة قابلة للتعديل حتى ٢٠٠٠ حرف وتحتفظ بفواصل السطور؛ لا يُفرض سعر ثابت.
- اختر إظهار القسم، وفعّل المحفظة أو إنستا باي أو الوسيلتين.
- اكتب رقم المحفظة المصرية ورابط إنستا باي الكامل الآمن. يمكن إيقاف كل وسيلة أو إخفاء القسم مع الاحتفاظ بالبيانات المحفوظة.
- في صفحة المريضة، الضغط على أيقونة المحفظة يكشف الرقم، وأيقونة إنستا باي تفتح الرابط المحفوظ.
- زر **إرسال إثبات الدفع عبر واتساب العيادة** يفتح رقم واتساب العيادة المحفوظ في بيانات الموقع. المريضة ترفق صورة الإيصال وتضغط إرسال داخل واتساب. الرقم مستقل عن رقم المحفظة.

إرسال الإثبات ومراجعته يتمان في واتساب؛ هذا التحديث يعرض وجهات الدفع والتعليمات، ولا يثبت نجاح التحويل البنكي ولا يغيّر حالة الحجز تلقائيًا.

## الحفظ والصلاحيات

إجراء paymentSettingsSave متاح للطبيب والأدمن فقط من الخادم؛ صلاحيات إدارة الموقع المفوضة للسكرتارية لا تسمح بتغيير بيانات الدفع. حارس مشترك يمنع تغيير إعدادات الدفع عبر مسار كتابة آخر بواسطة دور غير مصرح له. تُحفظ البيانات منفصلة في settings.payments مع مراجعة إصدار تمنع جلسة قديمة من استبدال تعديل أحدث، وتُسجل العملية في سجل العيادة.

يُتحقق من صيغة المحفظة، ورابط HTTPS بلا بيانات دخول، وصلاحية تفعيل الوسائل. نص الرسالة يُعرض كنص عادي ولا ينفذ HTML. بعد تغيير الإعدادات يمكن تحديث صفحة المريضة لقراءة القيم الجديدة.

## الاختبارات

- **537 اختبارًا آليًا ناجحًا، صفر فشل أو تخطٍ**؛ تشمل ست حالات موسعة عبر Node وEdge للصلاحيات والمعاينة القديمة والمدخلات غير الصحيحة وحفظ الرسالة والسجل.
- **11 تحققًا بالمتصفح**: الطبيب يضبط البيانات، الرسالة والسعر وفواصل السطور تظهر، المحفظة تكشف الرقم، إنستا باي يفتح الوجهة المحفوظة، زر الإثبات يستخدم رقم العيادة، المقاسات الأربعة سليمة، السكرتارية لا تملك المحرر، الأدمن يغيّر الرسالة والوجهات ويخفي القسم، ولا تنفيذ HTML أو أخطاء JavaScript.
- نجح فحص 269 ملف JavaScript وبناء الحزمة الموحدة وفحص رفع Vercel الذي يستبعد المصدر الخاص.

الاختبارات على بيانات مولدة وChromium. تم اعتراض فتح رابط إنستا باي في الاختبار ولم تُجرَ دفعات أو رسائل فعلية. Safari الحقيقي وإتمام التحويل البنكي والتسليم داخل واتساب غير مختبرة. أدلة المتصفح في [browser.json](qa-patient-payments-2026-11-04/browser.json)، وإعادة الاختبار عبر scripts/qa/payments-browser.cjs على نسخة prepare.cjs المعزولة.
