# اختيار بند الدفع وعرض سعره — 2026.11.04.3

الإصدار جاهز ويحتاج نشر خدمة clinic-api الجديدة قبل الواجهة. يتضمن إصلاح تعليق حفظ الدفع السابق، ولا يحتاج SQL جديدًا.

## الطبيب والأدمن

من **إعدادات حسابي ← إعداد وسائل الدفع** تظهر مجموعة **بنود الدفع وأسعارها**. توجد خانات ابتدائية للكشف والطوارئ والمتابعة، بلا أسعار مفترضة؛ اكتب السعر وفعّل البند ليظهر للمريضة. يمكن تغيير الاسم والسعر، إضافة بند مخصص، إخفاؤه أو حذفه، حتى ٢٠ بندًا. السعر بالجنيه المصري، يقبل الأرقام العربية أو الإنجليزية ومنزلتين عشريتين، ويمكن تحديد صفر للمتابعة المجانية.

الخانات الابتدائية غير المكتملة لا توقف حفظ رقم المحفظة أو رابط إنستا باي. عند حفظ بنود فعلية، تكون القائمة هي التي تحدد المبالغ المعروضة. تظل رسالة تعليمات الدفع وزر واتساب العيادة متاحين كما سبق.

## المريضة

تختار البند من قائمة **اختاري نوع الدفع**، فيظهر اسمه والمبلغ المطلوب، ثم تظهر وسيلتا الدفع المفعّلتان وزر إرسال الإثبات. رابط إنستا باي يظل الرابط الذي أدخله الطبيب؛ المبلغ الظاهر هو المبلغ المطلوب تحويله. إذا غيّر الطبيب البنود أو الأسعار ووصل التحديث للصفحة، تُلغى الاختيارات القديمة وتُطلب مراجعة المبلغ الحالي باختيار البند مجددًا. إخفاء جميع البنود الموجودة يمنع عرض وسائل الدفع دون اختيار سعر.

إذا لم تُضبط قائمة بنود أصلًا، يبقى عرض وسائل الدفع السابق متوافقًا. حذف القائمة كاملة يعيد هذا العرض؛ إخفاء قسم الدفع بالكامل متاح من إعداد ظهوره.

## الحفظ والصلاحيات والاختبارات

- التعديل للطبيب والأدمن فقط، مع حماية المراجعات المتزامنة وإيصالات الحفظ وإغلاق النافذة أثناء البطء.
- تُحفظ المبالغ كنص عشري ثابت، دون حسابات جمع مالية أو إنشاء تحويلات. الأسماء تُعرض كنص آمن. الأرقام السالبة والكسور الزائدة والمعرفات المكررة والمدخلات غير الصحيحة تُرفض دون تغيير المحفوظ.
- إصدارات محرر الدفع السابقة التي لا ترسل items تحتفظ بالقائمة الموجودة عند تعديل رقم المحفظة أو الرسالة.
- نجح **547 اختبارًا آليًا** دون فشل أو تخطٍ، و**64 تحققًا على PostgreSQL17.6 معزول**، منها حفظ أسعار البنود وتعديلها وإتاحتها للقراءة العامة.
- **40 تحققًا بالمتصفح**: 11 للبنود والأسعار، و11 لوسائل الدفع والرسالة، و18 لثبات الحفظ والإغلاق مع البطء والانقطاع وفقد الرد. شملت عروض 320 و390 و768 و1366 بكسل، وفحص 271 ملف JavaScript وبناء حزمة Vercel.

الأدلة في [verification.json](qa-payment-fees-2026-11-04/verification.json). بيانات الاختبار مولدة وChromium محلي؛ لم تُنفّذ دفعات أو رسائل فعلية، ولم يُختبر Safari الأصلي أو الإنتاج مباشرة. إعادة الاختبار عبر scripts/qa/payment-items-browser.cjs بعد prepare.cjs على جذر مؤقت منفصل.
