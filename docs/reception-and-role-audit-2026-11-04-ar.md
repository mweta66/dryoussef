# مراجعة الاستقبال والحضور والحسابات — ٤ نوفمبر ٢٠٢٦

الإصدار: **2026.11.04.4**. شملت المراجعة حساب الأدمن والطبيب والممرضة وسكرتارية الفروع الأربعة وإدخال البيانات، بالإضافة إلى صفحات المريضة وشاشتي دور مستقلتين. كل التغييرات التجريبية على بيانات مولدة معزولة؛ تأكيد تشغيل الإصلاح على الإنتاج متبقٍ.

## نطاق التجربة ونتائجها

- **554 اختبارًا آليًا**: صفر فشل وصفر تخطٍ، تشمل الصلاحيات وإيصالات الحفظ والحجز والملفات والطلبات والحذف والاستعادة والدفع، مع تطابق تنفيذ Node وEdge في المسارات المختبرة.
- **77 تحققًا على PostgreSQL17.6 معزول**: ترحيلات وإسقاطات القراءة والكتابة، تغيير حالة السكرتارية على حجز قديم، حفظ الحضور، إيصالات ضياع الرد ومنع تكرار الكتابة، رفض فرع آخر، وحفظ الملاحظات والتذكرة.
- **260 تحققًا وظيفيًا بالمتصفح** في هذه المراجعة، منها 58 للاستقبال والصلاحيات وحالات تأخر الاتصال، و90 لإجراءات الطاقم، و15 للأدمن، و15 للمريضة، و13 لدورة طلب الحجز وتغييره وإلغائه، و19 لقراءة السكرتارية وسحبها، و5 لحذف حالة واستعادتها، و16 لشاشتي الدور مع الطبيب والأدمن، و29 للدفع والأسعار وموثوقية حفظها. تتضمن الأعداد تحققات عدم وجود أخطاء JavaScript؛ لا تمثل عدد أزرار فريدة.
- **107 تحققات تنقل وصفحات**، و**696 فحص عرض** على أربعة مقاسات ووضعين، و24 تحققًا من تحميل الخط. الصفحات العامة وملف المريضة والتقارير ونوافذ الحجز والإعدادات ضمن الشاشات المفحوصة.
- **19 تحقق نسخ واستعادة على القرص**: تشفير وأجزاء وصور وPDF نشط ومؤرشف وسلامة الأصل، مع رفض التلف وكلمة السر الخاطئة.
- بناء الواجهة والخدمة وفحص 272 ملف JavaScript وحزمة Vercel نجحت. سكربت المتصفح الجديد نُفّذ كاملًا ضمن الفحوص الوظيفية.

جرّبت المراجعة الحجز ورفض التكرار وتغيير الحالات والحضور والتواصل والتأكيد وطلب المراجعة العاجلة وقرار الفريق الطبي والكشف وحفظه والانتقال للتالية وحجز المتابعة، وإجراءات حسابات الطاقم وتعديل بيانات المريضة والشكاوى والمرفقات وPDF، والإعدادات الإدارية والتصدير والتنظيف والاستعادة، وبنود الدفع وأسعارها وضبط ظهورها. تُظهر ملفات JSON المجاورة الخطوات الناجحة ونطاق كل مجموعة وحدودها.

## النشر والحدود

لا توجد ترحيلات SQL جديدة. الواجهة تستخدم نفس واجهتي commit وcheckinSet وتعمل مع الخدمة السابقة؛ إصلاح رفض الحجوزات القديمة يحتاج نشر خدمة **2026.11.04.4** أيضًا. بعد تحديث الخدمة يلزم تحديث الموقع والتأكد من تطابق الإصدارين وتجربة حجز تجريبي من السكرتارية ثم إعادة تحميله.

الاختبارات على Chromium ببيانات معزولة. المتبقي هو التحقق على حسابات الإنتاج وSafari الفعلي على الآيفون. لم تُجرَ مدفوعات أو اتصالات أو رسائل واتساب فعلية، ولم تُختبر كل قيمة ممكنة أو كل ترتيب تزامن أو استعادة حسابات Supabase Auth وكلمات مرورها. تقرير نجاح الاختبارات لا يثبت وحده صحة الشبكة أو إعدادات المشروع المنشور.
