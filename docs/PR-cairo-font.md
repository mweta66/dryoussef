أصبح خط الموقع Cairo في واجهة المرضى ولوحتي الأدمن والموظفين وشاشة الدور والخصوصية وصفحة 404 وشاشة التحميل، بما يشمل الأزرار والحقول والقوائم. يُحمّل ملف WOFF2 محليًا بحجم 100,680 بايت، ويضم العربية واللاتينية والأوزان 200–1000 مع ترخيص OFL؛ لا توجد طلبات إلى خدمة خطوط خارجية.

تستخدم تقارير العيادة وملفات الحالات الخط نفسه، بروابط محلية مطلقة تعمل داخل نوافذ about:blank، وتنتظر أزرار الطباعة اكتمال تحميل الخطوط. تغيرت إصدارات ملفات CSS وJavaScript المعدلة حتى تجلب الصفحات النسخة الجديدة.

التحقق: فحص 178 ملف JavaScript، ونجاح 254 اختبارًا. تجربة Chromium محلية للصفحات الست عند عرض 320 و390 و768 و1366 بكسل، وأمثلة من أقسام الأدمن وحساب الممرضة، دون أخطاء JavaScript أو تمدد أفقي في الزيارات المختبرة. أكد فحص الخط المستخدم فعليًا عبر Chrome DevTools أنه Cairo محلي، وأكد فحص PDF تضمين Cairo في تقريري العيادة والحالة. لم تُختبر Safari أو Firefox أو Edge فعليًا.

أُصلح أيضًا موعد بيانات اختبار إلغاء الحجز ليكون في الغد؛ كان الاختبار يعتمد على موعد اليوم ويفشل بعد مرور ساعة بدء العيادة، بصرف النظر عن تغيير الخط. لم تتغير قواعد الإلغاء في التطبيق.

هذا تعديل للواجهة والملفات الثابتة فقط، ولا يتطلب نشر خدمة clinic-api أو تغيير قاعدة البيانات. ينشر Vercel النسخة بعد دمج طلب التغيير حسب إعدادات المشروع.
